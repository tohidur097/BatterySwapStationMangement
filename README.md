Battery Swap Station Management System is a desktop application designed to manage core EV battery-swap station operations efficiently. The application is built using:
* C# Windows Forms
* .NET Framework 4.7.2
* SQL Server (SSMS)
* 3-Layer Architecture / Object-Oriented Programming (OOP)

## Requirements
Before running the project, make sure the following software is installed:
* Visual Studio 2019 / 2022
* .NET Framework 4.7.2
* SQL Server Express / MS SQL Server
* SQL Server Management Studio (SSMS)

## Quick Setup Steps

1. **Open the Project:
   * Open the solution file (`BatterySwapStationMangement.sln` / `.slnx`) in Visual Studio.
   * Rebuild the solution to restore all packages and dependencies.

2. **Database Configuration:
   * Open `Database.cs` inside the project.
   * Update the connection string with your local SQL Server instance name.
   * Run the application — required database connection will be initialized automatically.

3. **Run the Application:
   * Press **F5** or click Start in Visual Studio to launch the system.
